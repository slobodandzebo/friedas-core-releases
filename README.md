# Friedas Camper – releases

Installable builds of the **friedascamper.de** website by ESDRepairLab: the plugin **Friedas Core** (vehicle sync from Rent & Travel and Syscara, website enquiries, newsletter sign-ups) and the Bricks child theme **Friedas Camper**.

Each [release](../../releases) has the plugin zip `friedas-core-<version>.zip` and the theme zip `friedas-<version>.zip`, each with its signature (`.zip.rsig`). Sites read the latest release from here, check the signatures and show updates under *Plugins → Updates* and *Design → Themes*.

The source code is maintained in a private repository. Licence: proprietary.
